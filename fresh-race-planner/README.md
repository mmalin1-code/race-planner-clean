# Fresh Race Planner Repo

This folder is a **clean new repository starter** to avoid the current deployment confusion.

## 1) Create a brand-new GitHub repo
- Name it: `race-planner-clean` (or any name)
- Leave it empty (no template needed)

## 2) Upload these files
Upload everything from this folder (`fresh-race-planner/`) into the new repo root.

Required files:
- `index.html`

## 3) Enable GitHub Pages
- Settings → Pages
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/(root)`

## 4) Working URL pattern
- `https://<your-username>.github.io/race-planner-clean/`

## 5) If it still shows GitHub 404
- Confirm repo is public
- Wait 2–5 minutes
- Check Actions tab for failed Pages deploy
